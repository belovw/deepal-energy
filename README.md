# Deepal Energy — вариант A (dumpsys com.mega.car.CarService)

Источник данных: живые CAN-сигналы из вывода `dumpsys com.mega.car.CarService`.

Что уже есть:
- `energy/DumpsysEnergySource.kt` — парсер строк `Группа/Сигнал, {JSON}` и чтение сигналов:
  заряд SOC, запас хода на топливе, статус ДВС, направление потока энергии, флаг подзарядки от ДВС, передача.

Что не проверено:
- Формат строки и ключ `"value"` взяты из прошлого проекта, но не сверены с полным выводом dumpsys.
- Обычное приложение может не получить вывод dumpsys (shell-доступ). Пока работает только при запуске через ADB или с системными правами.
- Сборка Gradle не запускалась (нет Android SDK).

Не подключено к экрану: `FuelEnergyReader` и UI остаются из Lynk-версии. Подключение — следующий шаг.
